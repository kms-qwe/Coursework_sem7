# Мини-проверка

Перед полным экспериментом решил проверить, работает ли основная ветка B + GReg. Для первого запуска сократил число вариантов и повторов. Датасет оставил полным.

## Что вошло в первый запуск

| Часть эксперимента | Мини-запуск | Полный эксперимент |
|---|---|---|
| Уровни | Только 70% | 30, 50, 70, 90% |
| Поиск | Только B, 40 планов | A и B, по 40 планов |
| Отбор для дообучения | Топ-3 | Топ-5 каждого варианта |
| Зерна обучения | Только 0 | 0, 1, 2 |
| GReg | Только для плана B | Для B и равномерного L1-плана |
| Планы вне топа | Не проверял | Еще 5 на уровне 50% |
| Бейзлайны | Взял результаты первого локального запуска | Повторил все методы с тремя зернами в Colab |

Так проверил поиск B, восстановление BN и постепенное удаление каналов. Поиск A, остальные уровни, повторные обучения и дополнительные абляции оставил для полного эксперимента.

## Запуск

Обучение проходило локально через MPS. На уровне 70% оставлял не меньше 8 каналов в группе. Для 40 планов B измерил Dice val после удаления каналов и восстановления BN. Три лучших дообучил по 20 эпох, затем выбрал победителя по val.

С его планом выполнил отдельный запуск из весов `base.pth`: 10 эпох GReg, удаление каналов, восстановление BN и 20 эпох дообучения.

```bash
.venv/bin/python src/own_method_mini.py
```

## Отбор по трем условиям

При удалении ровно 70% каналов планы B давали больше GMACs, чем равномерный прунинг 70%. Подгонка по трем условиям потребовала удалить больше каналов, чтобы одновременно выполнить ограничения по каналам, параметрам и GMACs.

Победил план 6: удалено 77,7% каналов, осталось 837 203 параметра, 0,715 GMACs, файл 3,3 МБ. У L1 70%: 2,17 млн параметров и 0,718 GMACs.

## Результаты

Одно зерно, после дообучения. L1 взят из первого бейзлайна.

| Модель | Параметры, млн | Dice test | Dice PH2 | CPU 1 поток, мс |
|---|---:|---:|---:|---:|
| L1 70% | 2,17 | 0,9066 | 0,8991 | 12,6 |
| Поиск B | 0,84 | 0,9102 | 0,9011 | 15,2 |
| Поиск B + GReg | 0,84 | 0,9161 | 0,9198 | 15,0 |

При GReg Dice val до физического удаления был 0,9133, сразу после: 0,9132. Без дообучения, после восстановления BN, Dice test составил 0,9037 против 0,5040 у B без GReg.

Метод дал меньшую модель и более высокий Dice в одном запуске, но работал медленнее равномерного L1. Для дальнейшего сравнения добавил остальные уровни, три зерна и абляции.

В полном запуске на 70% поиск выбрал другой план числа каналов по группам. Состав блоков сохранился, но число каналов изменилось: осталось 0,62 млн параметров вместо 0,84 млн мини-запуска.
