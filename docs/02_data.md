# Датасеты и метрики

## Данные

Использовал дерматоскопические изображения и бинарные маски кожных образований.

| Датасет / часть | Изображений | Назначение |
|---|---:|---|
| ISIC 2016 Part 1, train | 810 | Обучение и пересчет BatchNorm |
| ISIC 2016 Part 1, val | 90 | Выбор эпох и кандидатов |
| ISIC 2016 Part 1, test | 379 | Оценка качества |
| PH2 | 200 | Внешний тест |

Из 900 официальных обучающих изображений ISIC выделил 90 для val, зерно разбиения 42. Разбиение одинаковое во всех экспериментах. PH2 взял в готовой версии 256×256 из `ahishamm/ph2_masks` на Hugging Face. Test и PH2 не участвовали в выборе кандидатов и эпох.

## Подготовка

Изображения переводил в RGB и изменял до 256×256 без сохранения пропорций. Маски изменял билинейной интерполяцией и бинаризовал по порогу 127. Перед сетью изображения делил на 255 и нормализовал статистиками ImageNet.

Аугментации train: отражения, поворот, масштаб от 0,8 до 1,2, сдвиг, яркость, контраст и насыщенность. Геометрические преобразования изображения и маски согласованы. На остальных частях аугментаций нет.

Кэш: `data/cache/{train,val,test,ph2}_256.npz`. Поля: `X`: изображения uint8, `Y`: булевы маски, `ids`: идентификаторы.

```bash
scripts/download_data.sh
.venv/bin/python src/prepare_data.py
```

## Метрики

Dice и IoU считал по бинарным маскам отдельно для каждого изображения, затем усреднял. В полном эксперименте дополнительно считал среднее и стандартное отклонение по трем зернам обучения.

Код: [prepare_data.py](../src/prepare_data.py), [common.py](../src/common.py).
